# Demo Icon System Package - Tidepool Tasks

This generated demo package shows the mobile icon system workflow end to end in a compact form. Tidepool Tasks is a fictional calm planning app; the package keeps the full decision trail while limiting the asset set to five SVG masters.

## Flow

1. `brand-dna.md` defines the inherited visual language.
2. `system-rules.md` locks the grid, stroke, corner, state, naming, and accessibility rules.
3. `vocabulary.md` translates the product surfaces into icon metaphors and risks.
4. `selected/rationale.md` records why the final icons were chosen.
5. `reviews/scorecard.md` scores the selected set and notes residual risks.
6. `package-notes.md` explains how the package should be consumed.

The SVGs are original, monochrome, tintable masters on a 24 by 24 grid.
