icon libraries listed below. Each library's license is reproduced upstream
at the linked URL. Files are used unmodified; the corpus calibrates against
their original geometry.

`user-gendered.svg`, `notification-color-state.svg`) are original work for

## Refresh discipline

The mappings above are mechanically reproduced in `manifest.json` (written by
`scripts/fetch_references.py`). If you add or replace a file, update both
this `ATTRIBUTIONS.md` and re-run `fetch_references.py --update` so the
manifest stays consistent.
