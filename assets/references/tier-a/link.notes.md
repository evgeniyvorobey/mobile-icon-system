## Why this tier
Two paths — interlocking arc-segments at exactly 45° (diagonal). Each link is 5pt radius. **Interlocking is created by paths NOT closing** — each path is partial loop with opening that other path's arc passes through. Sophisticated trompe-l'œil — links don't actually chain, they fake the chaining via partial arcs.

## What a generator should learn
Chain links use partial-arc trompe-l'œil, not actual interlocking.
