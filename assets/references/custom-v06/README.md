# custom-v06 reference anchors

This directory is an additive v0.6 calibration corpus. Every asset here is original repo-authored work, included to cover visual-style and motion cases that the upstream-fetched corpus does not redistribute.

## Anchors

- `pixel-bolt-16.svg` - native 16 pt pixel-art construction.
- `isometric-cube-24.svg` - compact 3D/isometric planar construction.
- `jitter-pencil-24.svg` - deterministic hand-drawn path jitter, seed `v06-jitter-pencil-24-seed-137`.
- `motion-pulse.json` + `motion-pulse-static.svg` - motion/static reduced-motion fallback pair.

Each `.svg` and `.json` asset has a sibling `.notes.md` file covering structure observations, generator lessons, and licensing/provenance.
