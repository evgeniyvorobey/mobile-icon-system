# Gaming & Entertainment

## Industry overview

Gaming apps include casual (Candy Crush, Royal Match, Wordle), match-3/puzzle (Two Dots), MOBA companions (Riot Mobile), shooter companions (PUBG/Fortnite mobile launchers), gacha/RPG (Genshin Impact, Honkai), social gaming (Roblox, Among Us), platforms (Xbox Game Pass mobile, PlayStation App, Steam Mobile), and competitive (Discord, Twitch, FACEIT). Gaming has high prevalence (Games is App Store's #1 category by submission volume) and medium-to-high cliché density (controllers always look outdated; XP bars conflict with progress bars). The domain reuses Education's streak/XP/level vocabulary and adds session-specific metaphors (lobby, party, ranked, queue, cosmetic, loot box, season pass). PlayStation App and Xbox mobile pioneered the friend presence indicator. Steam Mobile pioneered the wishlist + library + store triad. Riot Mobile pioneered ranked tier display.

## Metaphor catalog

### Controller
- **Recommended forms**: simplified gamepad (D-pad on left, ABXY on right), OR generic rectangle with two circles
- **Cliché**: detailed Xbox/PlayStation controller (couples to brand)
- **Reference**: Xbox app; PlayStation App; Steam Mobile

### Achievement / Trophy
- **Recommended forms**: trophy silhouette OR star burst with rank tier (bronze/silver/gold)
- **Cliché**: medal (military)
- **Reference**: PlayStation trophies; Xbox achievements; Steam achievements

### Level up
- **Recommended forms**: up arrow + number badge OR sparkle + arrow up
- **Cliché**: just an up arrow (loses level)
- **Reference**: Diablo IV mobile; gacha games; Duolingo level-up

### XP / Experience
- **Recommended forms**: lightning + "XP" badge OR star + number
- **Cliché**: dollar sign
- **Reference**: Genshin Impact XP bar; Pokémon Go XP

### Leaderboard / Ranked
- **Recommended forms**: 1-2-3 podium silhouette OR list with rank numbers
- **Cliché**: trophy (means single-achievement)
- **Reference**: Riot Games rank tiers; FACEIT; Steam leaderboards

### Friend / Add Friend
- **Recommended forms**: person silhouette + plus
- **Cliché**: handshake (formal)
- **Reference**: Steam friends; Discord; Xbox friends
- **Universal vocabulary cross-ref**: extends [Follow / Add Friend](../icon-vocabulary.md#follow--add-friend)

### Party / Group invite
- **Recommended forms**: 2-3 person silhouettes + invite/plus
- **Cliché**: same as social Group
- **Reference**: Discord stage; Apex Legends party; Fortnite party-up
- **Universal vocabulary cross-ref**: extends [Group / Community](../icon-vocabulary.md#group--community)

### Lobby / Matchmaking
- **Recommended forms**: clock + person OR door + person OR queue dots
- **Cliché**: just clock
- **Reference**: League of Legends client; Apex Legends lobby

### Match / Game in progress
- **Recommended forms**: VS-shield silhouette OR controller + dot indicator
- **Cliché**: just controller
- **Reference**: League of Legends match; Riot Mobile

### Ranked tier (Iron, Bronze, Silver, Gold, Platinum, Diamond)
- **Recommended forms**: shield/badge with tier color and roman numeral OR distinct tier glyph per tier
- **Cliché**: just text label
- **Reference**: League of Legends ranked emblems; Valorant; Apex

### Cosmetic / Skin
- **Recommended forms**: shirt silhouette OR sparkle + item glyph
- **Cliché**: trophy (different)
- **Reference**: Fortnite skins; League skins; Genshin character cards

### Loot box / Reward
- **Recommended forms**: chest silhouette (closed) — paired with open-chest for state pair
- **Cliché**: literal treasure chest with detail (over-detailed)
- **Reference**: Overwatch loot box (deprecated); Hearthstone packs

### Season pass / Battle pass
- **Recommended forms**: track with markers OR rectangle with progress bar + lock/unlock states
- **Cliché**: just progress bar
- **Reference**: Fortnite Battle Pass; Apex Battle Pass; Pokémon Go season

### Currency (in-game gold, gems, V-bucks)
- **Recommended forms**: coin + game-specific glyph OR diamond/gem
- **Cliché**: dollar sign
- **Reference**: Fortnite V-Bucks; Genshin Primogems; Roblox Robux
- **Universal vocabulary cross-ref**: extends [Cash / Money](../icon-vocabulary.md#cash--money)

### Quest / Mission
- **Recommended forms**: scroll OR check-list with arrow
- **Cliché**: scroll alone (anachronistic)
- **Reference**: Genshin daily commissions; Diablo bounties
- **Universal vocabulary cross-ref**: extends [Document](../icon-vocabulary.md#document)

### Inventory / Bag
- **Recommended forms**: bag/backpack silhouette OR grid of item slots
- **Cliché**: same as commerce Bag (different concept)
- **Reference**: Diablo inventory; Genshin bag; Minecraft inventory
- **Universal vocabulary cross-ref**: distinct from [Bag](../icon-vocabulary.md#bag)

### Equip / Equipment
- **Recommended forms**: armor/sword silhouette OR slot grid with item
- **Cliché**: detailed sword
- **Reference**: RPG mobile games; Diablo Immortal

### Health / HP bar
- **Recommended forms**: heart + filled bar OR cross + bar
- **Cliché**: heart conflates with like
- **Reference**: every RPG; Pokémon Go
- **Universal vocabulary cross-ref**: extends [Like / Favorite](../icon-vocabulary.md#like--favorite) heart in game context

### Mana / Energy
- **Recommended forms**: blue drop OR lightning bolt OR star
- **Cliché**: dollar sign
- **Reference**: every fantasy RPG; League of Legends

### Voice chat (in game)
- **Recommended forms**: mic + headset OR speaker + dot
- **Cliché**: just mic
- **Reference**: Discord; Xbox party chat; PlayStation party

### Stream / Twitch
- **Recommended forms**: dot + arcs (live broadcast) OR play triangle on shield
- **Cliché**: TV antenna
- **Reference**: Twitch icon; YouTube Gaming; Facebook Gaming
- **Universal vocabulary cross-ref**: extends [Live / Broadcast](../icon-vocabulary.md#live--broadcast)

### Online status (presence)
- **Recommended forms**: filled dot in green/yellow/gray + paired with shape (filled/half/dot/empty)
- **Cliché**: color-only encoding
- **Reference**: Discord status; Xbox presence; Steam status

### Cloud save
- **Recommended forms**: cloud + save (floppy or down-arrow into cloud)
- **Cliché**: just cloud (means generic sync)
- **Reference**: Steam Cloud; Xbox Cloud Gaming; PlayStation Cloud Saves
- **Universal vocabulary cross-ref**: extends [Sync / Cloud](../icon-vocabulary.md#sync--cloud)

## Cliché map for gaming

| Cliché | Why it fails | Alternative |
|---|---|---|
| Detailed branded controller | Couples to PS/Xbox brand | Generic gamepad silhouette |
| Heart for HP and like | Two meanings; OK with context | Game HP heart filled-bar; like heart standalone |
| Trophy for everything | Loses tier (rank vs achievement vs season) | Tier shield for rank; trophy for achievement |
| Dollar for in-game currency | Locale fail + game-context fail | Coin or gem with game glyph |
| Scroll for quest | Anachronistic | Checklist + arrow |
| Same chat icon as social | Loses game context | Voice chat = mic + headset |
| Color-only online status | CVD-fail | Filled/half/dot/empty shape pair |
| Refresh for re-queue | Loses queue | Queue dots OR magnifying-glass spinning |
| Sword for "fight" generally | Genre-specific | Use VS-shield or match icon for matches |
| Cloud alone for cloud save | Means sync | Cloud + floppy or arrow |

## State-pair examples

1. **Match: Searching / Found / In progress / Ended (W/L)** — 4-state
2. **Loot box: Sealed / Opening / Opened / Empty** — 4-state animation
3. **Quest: Available / Active / Complete / Turned-in** — 4-state
4. **Online: Online / In game / Away / Offline** — 4-state presence dot with shape encoding
5. **HP: Full / Damaged / Critical / Dead** — 4-state heart-bar with shape change

## Industry-leading reference

PlayStation App / Xbox app (friend presence and trophy/achievement vocabulary). Steam Mobile (library/wishlist/store triad). Riot Mobile (League/Valorant) (ranked tier emblems). Discord (voice chat and party). Genshin Impact / Diablo Immortal (inventory, quest, currency vocabulary).

[Like / Heart](../icon-vocabulary.md#like--favorite) used as HP in game context only. [Star](../icon-vocabulary.md#star--rating) = Achievement tier. [Group](../icon-vocabulary.md#group--community) = Party. [Microphone](../icon-vocabulary.md#microphone) = Voice chat (game variant). [Cash](../icon-vocabulary.md#cash--money) = In-game currency. [Cloud / Sync](../icon-vocabulary.md#sync--cloud) = Cloud save. [Live / Broadcast](../icon-vocabulary.md#live--broadcast) = Streaming.
