# Social & Community

## Industry overview

Social apps include broadcast (Twitter/X, Threads, Bluesky, Mastodon), photo (Instagram), short video (TikTok, Reels, Shorts), long video (YouTube), community (Reddit, Discord, Slack), professional (LinkedIn), and ephemeral (Snap, BeReal). The domain has dense engagement vocabulary that universal library covers thinly: reactions (vs simple like), boost (vs share), DM (vs chat), stories (vs feed), groups (vs communities). Twitter/X established the retweet/repost as visually distinct from share. Instagram established the stories ring (gradient ring around avatar = unviewed story). Discord established the server/channel/DM three-tier hierarchy. Reddit's upvote/downvote is canonical inverse-pair encoding.

## Metaphor catalog

### Reactions (multi-emoji)
- **Recommended forms**: 5–7 face glyphs in horizontal row, with `+` for more
- **Cliché**: just thumbs up
- **Reference**: Slack reactions; Discord reactions; LinkedIn reactions
- **Universal vocabulary cross-ref**: extends [Like / Favorite](../icon-vocabulary.md#like--favorite)

### Boost / Promote
- **Recommended forms**: rocket OR upward arrow + sparkle OR megaphone
- **Cliché**: just an arrow up (loses amplification)
- **Reference**: Twitter/X promote; Instagram boost
- **Universal vocabulary cross-ref**: distinct from [Share](../icon-vocabulary.md#share)

### Mention (@user)
- **Recommended forms**: `@` symbol in rounded square OR person+`@`
- **Cliché**: just person icon
- **Reference**: Twitter mentions; Slack; Discord
- **Universal vocabulary cross-ref**: distinct from [Profile / Account / Me](../icon-vocabulary.md#profile--account--me)

### Hashtag / Topic
- **Recommended forms**: `#` symbol — text-glyph icon
- **Cliché**: tag silhouette (means discount)
- **Reference**: Twitter hashtag pages; TikTok hashtag pages
- **Universal vocabulary cross-ref**: distinct from [Tag / Discount](../icon-vocabulary.md#tag--discount)

### Stories ring (unviewed indicator)
- **Recommended forms**: avatar circle + 2–3pt gradient ring around it
- **Cliché**: notification dot (means unread, but stories has its own pattern)
- **Reference**: Instagram Stories tray; Snap; LinkedIn Stories
- **Universal vocabulary cross-ref**: extends [Profile / Account / Me](../icon-vocabulary.md#profile--account--me) avatar

### DM / Direct message
- **Recommended forms**: paper airplane (Instagram convention) OR envelope-with-arrow OR speech bubble + lock
- **Cliché**: same icon as Send (different intent)
- **Reference**: Instagram DM; Twitter DM; Discord
- **Universal vocabulary cross-ref**: distinct from [Send](../icon-vocabulary.md#send) and [Messages / Chat](../icon-vocabulary.md#messages--chat)

### Groups vs Communities
- **Recommended forms**: 2 overlapping heads (group); 4+ heads in cluster OR castle/server icon (community)
- **Cliché**: same icon for both
- **Reference**: Facebook Groups; Reddit subreddits; Discord servers
- **Universal vocabulary cross-ref**: extends [Group / Community](../icon-vocabulary.md#group--community)

### Moderation (mute, block, report)
- **Recommended forms**: speaker-slash (mute); person-slash (block); flag (report)
- **Cliché**: red X for everything
- **Reference**: Twitter/X mute, block, report; Reddit moderator tools
- **Universal vocabulary cross-ref**: extends [Mute](../icon-vocabulary.md#mute) and [Block / Unfollow](../icon-vocabulary.md#block--unfollow)

### Upvote / Downvote
- **Recommended forms**: up arrow + down arrow paired, with state-fill on selected
- **Cliché**: just arrows (no state); thumbs up/down (Slack reaction style — different)
- **Reference**: Reddit (canonical); Hacker News
- **Universal vocabulary cross-ref**: distinct from [Like / Favorite](../icon-vocabulary.md#like--favorite)

### Repost / Retweet / Reblog
- **Recommended forms**: two arrows in circular arrangement (forms square loop) — distinct from refresh
- **Cliché**: refresh icon
- **Reference**: Twitter/X retweet; Mastodon boost; Tumblr reblog
- **Universal vocabulary cross-ref**: distinct from [Refresh](../icon-vocabulary.md#refresh) and [Share](../icon-vocabulary.md#share)

### Quote / Quote-tweet
- **Recommended forms**: quote-marks `""` + arrow OR speech bubble inside speech bubble
- **Cliché**: just retweet (loses commentary)
- **Reference**: Twitter/X quote-tweet; Bluesky quote

### Feed type (For You / Following / Trending)
- **Recommended forms**: For You = sparkle + person; Following = person+person; Trending = flame OR upward arrow
- **Cliché**: same icon for all three
- **Reference**: Twitter/X For You; TikTok For You; Threads
- **Universal vocabulary cross-ref**: extends [Trending](../icon-vocabulary.md#trending) for trending only

### Save (separate from like)
- **Recommended forms**: bookmark
- **Cliché**: heart (means like; conflated)
- **Reference**: Instagram saved; Twitter/X bookmarks; Reddit save
- **Universal vocabulary cross-ref**: distinct from [Like / Favorite](../icon-vocabulary.md#like--favorite)

### Live (live stream)
- **Recommended forms**: dot + radiating arcs OR "LIVE" badge
- **Cliché**: TV antenna
- **Reference**: Instagram Live; YouTube Live; Twitch
- **Universal vocabulary cross-ref**: extends [Live / Broadcast](../icon-vocabulary.md#live--broadcast)

### Verified (badge)
- **Recommended forms**: filled circle/star with check inside
- **Cliché**: just check (no badge container)
- **Reference**: Twitter/X verified; Instagram blue check; LinkedIn
- **Universal vocabulary cross-ref**: extends [Success](../icon-vocabulary.md#success) check

### Profile / Avatar
- **Recommended forms**: circle (image-cropped) — never default-illustrated person
- **Cliché**: gendered figure as default
- **Reference**: Instagram, Twitter, LinkedIn — all use circle
- **Universal vocabulary cross-ref**: extends [Profile / Account / Me](../icon-vocabulary.md#profile--account--me)

### Send DM (compose)
- **Recommended forms**: pencil + envelope OR pencil + speech bubble
- **Cliché**: just pencil (means edit)
- **Reference**: Instagram DM compose; Twitter/X compose DM
- **Universal vocabulary cross-ref**: composes [Compose / New Document](../icon-vocabulary.md#compose--new-document) + [Messages / Chat](../icon-vocabulary.md#messages--chat)

### Trending / Explore tab
- **Recommended forms**: compass (Instagram convention); flame; magnifying glass + sparkle
- **Cliché**: just magnifying glass (means search)
- **Reference**: Instagram Explore (compass); Twitter/X trending
- **Universal vocabulary cross-ref**: extends [Search / Discover](../icon-vocabulary.md#search--discover) and [Trending](../icon-vocabulary.md#trending)

### Notifications (granular)
- **Recommended forms**: bell (general); heart (like); `@` (mention); person+plus (follow); bubble (comment)
- **Cliché**: bell only for everything
- **Reference**: Twitter/X notification tabs; Instagram activity tabs
- **Universal vocabulary cross-ref**: extends [Notifications / Inbox](../icon-vocabulary.md#notifications--inbox)

### Voice clip / Voice note
- **Recommended forms**: waveform inside chat bubble OR mic + bubble
- **Cliché**: just mic
- **Reference**: WhatsApp voice notes; Telegram; Voice Tweet
- **Universal vocabulary cross-ref**: composes [Microphone](../icon-vocabulary.md#microphone) + bubble

### Channel / Server (Discord-style)
- **Recommended forms**: `#` (text channel); speaker (voice channel); list (forum channel)
- **Cliché**: just folder
- **Reference**: Discord channel types; Slack channels
- **Universal vocabulary cross-ref**: distinct from [Folder](../icon-vocabulary.md#folder)

## Cliché map for social

| Cliché | Why it fails | Alternative |
|---|---|---|
| Heart for like + save | Two meanings | Heart = like (public); Bookmark = save (private) |
| Send arrow for DM and message | Conflates send with chat | DM has its own metaphor per app convention |
| Refresh for repost | Same shape, different action | Repost has SQUARE LOOP of two arrows |
| Single bell for all notifications | Loses granularity | Per-type icons with bell as parent |
| Compass for everything "discover" | Compass is now overloaded | Pair compass + label for explore; sparkle for For You |
| Thumbs for everything social | Cultural baggage | Reaction set; specific shapes per intent |

## State-pair examples

1. **Like outlined / Like filled** — same as universal heart, high-frequency
2. **Follow / Following / Followed-back / Mutual** — 4-state
3. **Story: Unviewed (gradient ring) / Viewed (gray ring) / Your story (plus) / Add story** — 4-state ring
4. **Notification: Unread / Read** — bell with dot / bell plain
5. **DM: Unread / Read / Typing / Sent / Delivered / Seen** — 6-state per-message indicator

## Industry-leading reference

Twitter/X (retweet/quote vocabulary, For-You algorithm icons). Instagram (stories ring, save bookmark, DM paper airplane). Discord (server/channel/DM hierarchy). Reddit (upvote/downvote, moderation). WhatsApp (voice-note, read-receipt states).
