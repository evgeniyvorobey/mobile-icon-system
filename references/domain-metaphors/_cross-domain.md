# Cross-Domain Patterns

The same iconographic shape recurs across domains with semantic shifts. The skill must catalog these so brand work in Domain A doesn't accidentally adopt Domain B's connotation. Load this file in Phase 6 alongside the matched domain catalog and [`../icon-vocabulary.md`](../icon-vocabulary.md). For multi-domain apps (fintech with chat, fitness with social feed, gaming with marketplace), use this file aggressively to disambiguate.

Each pattern documents the shape, the meanings it carries across domains, and a disambiguation rule.

## Pattern 1. The "Send" cluster

- **Music**: paper airplane = send to chat
- **Social**: paper airplane = DM (Instagram convention)
- **Finance**: paper airplane = send money (Cash App convention)
- **Universal**: paper airplane = generic submit

**Disambiguation:** paper-airplane needs target context in finance ("Send $50 to Alex"). In single-domain apps the metaphor is safe; in cross-domain apps (e.g., a fintech with chat and payments), use distinct icons: pay = card+arrow; chat send = paper airplane.

## Pattern 2. The "Streak flame" cluster

- **Health**: streak = flame + day count (consistency)
- **Education**: streak = flame + day count (Duolingo)
- **Social**: snap streak = flame between friends

**Disambiguation:** shape is identical, semantics is "consistency over time." Safe to reuse across domains; brand color differentiates.

## Pattern 3. The "Heart" cluster

- **Universal**: like / favorite (single-tap toggle, social context)
- **Music**: Liked Songs (high-frequency primary action)
- **Health**: heart rate (anatomical, not romantic)
- **Gaming**: HP / lives (filled-bar, count)

**Disambiguation:** anatomical-asymmetric heart for vitals; romantic heart for like/save; heart-bar with explicit count for gaming HP.

## Pattern 4. The "Lightning" cluster

- **Finance**: express checkout / fast transfer
- **E-commerce**: Buy Now / Express
- **Gaming**: energy / mana / XP
- **Dev tools**: webhook / serverless function
- **Transportation**: EV charging

**Disambiguation:** lightning needs noun pairing: bolt+plug (EV); bolt+box (fast checkout); bolt+λ (function); bolt+arrow (webhook). Standalone lightning means "fast" generically.

## Pattern 5. The "Trophy / Star / Badge / Achievement" cluster

- **Education**: badge (skill); achievement (milestone); trophy (completion)
- **Gaming**: trophy (achievement); ranked emblem (tier); star (rating)
- **E-commerce**: star (rating); loyalty star (points)
- **Universal**: star = rating

**Disambiguation:** trophy = single milestone; shield = skill or tier; star = rating or points (with count). Never use trophy for "rank" — rank gets shield or tier emblem.

## Pattern 6. The "Refresh / Cycle" cluster

- **Universal**: refresh = reload
- **Music**: repeat = loop playback
- **Finance**: recurring transaction
- **Productivity**: recurring event
- **Dev tools**: redeploy (NOT refresh)

**Disambiguation:** refresh = single-arrow circle; repeat = circular arrow with explicit closure point and arrowhead; recurring = composes refresh + domain noun (calendar, cash, etc.); redeploy uses rocket+arrow not refresh.

## Pattern 7. The "Pin / Bookmark / Save / Wishlist" cluster

- **Universal**: bookmark = save in library
- **Productivity**: pushpin = pinned page
- **E-commerce**: bookmark = wishlist (NOT heart)
- **Social**: bookmark = save post (NOT heart)
- **Maps**: pin = location (NOT save)

**Disambiguation:** pin = location specifically (teardrop); pushpin = "pinned to top" (45° angle pin); bookmark = saved-for-later; heart = like/favorite. Four distinct shapes.

## Pattern 8. The "Cloud" cluster

- **Universal**: sync / backup
- **Dev tools**: cloud function / cloud service
- **Gaming**: cloud save
- **Music**: cloud library

**Disambiguation:** bare cloud = sync state; cloud + arrow = up/download; cloud + λ = serverless; cloud + floppy = save. Always pair cloud with target noun.

## Pattern 9. The "Group / People" cluster

- **Universal**: 2-3 overlapping heads = group
- **Social**: group vs community vs server (three scales)
- **Productivity**: shared workspace
- **Gaming**: party (small) vs guild (large)

**Disambiguation:** scale matters: 2 heads = pair; 3 heads = group; 4+ or castle = community/guild. Use scale as semantic encoding.

## Pattern 10. The "Calendar event" cluster

- **Universal**: calendar = schedule
- **Productivity**: calendar event = single instance
- **Health**: dose timer = scheduled medication
- **Finance**: dividend date / tax deadline

**Disambiguation:** bare calendar = schedule view; calendar + dot = single event; calendar + circular arrow = recurring; calendar + pill = dose; calendar + cash = financial deadline.
