# Productivity & Notes

## Industry overview

Productivity apps include note-takers (Notion, Apple Notes, Bear, Obsidian, Craft, Logseq, Mem), task managers (Todoist, Things, OmniFocus, TickTick, Linear mobile, Asana, ClickUp), kanban (Trello, Jira mobile), calendars (Fantastical, Cron/Notion Calendar, Google Calendar, Cal.com), and writing (Ulysses, iA Writer, Drafts). The domain's distinguishing feature is **structural metaphors**: page hierarchies, bidirectional links, embeds, blocks, kanban columns. Notion pioneered the "block" with handles. Obsidian/Logseq pioneered bidirectional link visualization. Linear pioneered the keyboard-first issue UI on mobile. The cliché trap is moderate: most productivity icons (checkbox, list, plus) are universal. The distance comes from structural concepts (block handle, page hierarchy, link arrow direction) that don't exist in universal library.

## Metaphor catalog

### Page hierarchy / Outline
- **Recommended forms**: indented horizontal lines (3 lines, second/third indented), OR tree with branches
- **Cliché**: folder tree (reads as file system); generic list (loses hierarchy)
- **Reference**: Notion sidebar; Obsidian outline; Roam Research

### Bidirectional link
- **Recommended forms**: two arrows in opposite directions OR two square brackets `[[ ]]`
- **Cliché**: chain link (means generic hyperlink)
- **Reference**: Obsidian backlinks panel; Roam; Logseq

### Embed / Inline content
- **Recommended forms**: rectangle inside rectangle with corner indicator
- **Cliché**: same as picture-in-picture (different concept)
- **Reference**: Notion embed block; Confluence

### Block handle (drag handle for content blocks)
- **Recommended forms**: 6-dot grid (2×3) OR vertical handlebar `⋮⋮`
- **Cliché**: 3-dot menu (means more options); hamburger (means navigation)
- **Reference**: Notion block handle (canonical); Coda; Linear comments

### Table
- **Recommended forms**: 2×3 grid of cells (NOT 3×3 — adds noise)
- **Cliché**: spreadsheet with cell references
- **Reference**: Notion table; Airtable; Coda

### Kanban column / Board
- **Recommended forms**: 3 vertical columns of equal width with horizontal lines inside (representing cards)
- **Cliché**: just 3 columns (loses task context); single tall list (loses kanban)
- **Reference**: Trello board; Linear board view; Jira mobile board

### Sprint / Cycle
- **Recommended forms**: arc segment + arrow (segment of cycle), OR time-window rectangle
- **Cliché**: just calendar (loses sprint metaphor)
- **Reference**: Linear cycles; Jira sprints; Asana

### Checklist with subtasks (nested)
- **Recommended forms**: parent checkbox + 2 indented child checkboxes
- **Cliché**: flat checklist (loses nesting)
- **Reference**: Things 3 nested checklists; Todoist subtasks; Apple Reminders

### Mind map / Graph view
- **Recommended forms**: 3 nodes connected by lines (one center, two branches)
- **Cliché**: organizational chart (top-down)
- **Reference**: Obsidian graph view; MindNode; XMind

### Calendar event (single instance)
- **Recommended forms**: small rectangle on calendar grid OR calendar with dot
- **Cliché**: full calendar (means schedule); clock alone (means time)
- **Reference**: Fantastical event glyph; Google Calendar event chip

### Recurring event
- **Recommended forms**: calendar + circular arrow OR calendar with stack
- **Cliché**: just refresh (loses calendar context)
- **Reference**: Fantastical recurrence; Google Calendar repeat

### Time block / Focus session
- **Recommended forms**: rectangle with progress bar, OR clock face with sector highlighted
- **Cliché**: tomato (Pomodoro is brand-coupled)
- **Reference**: Notion Calendar focus; Sunsama; Reclaim.ai

### Tag (note tag)
- **Recommended forms**: hash `#` symbol OR price-tag silhouette
- **Cliché**: same as discount tag (different domain)
- **Reference**: Bear tags; Notion tags; Obsidian tags

### Slash command / Command palette
- **Recommended forms**: forward slash `/` in rounded square OR `⌘` symbol
- **Cliché**: gear (means settings); search (means find)
- **Reference**: Linear command menu; Notion slash menu; Raycast

### Database / Collection (Notion-style)
- **Recommended forms**: 3 stacked rectangles (cylinder for traditional DB; flat stack for "collection")
- **Cliché**: cylinder (means backend database)
- **Reference**: Notion database views; Coda; Airtable

### Filter view (database)
- **Recommended forms**: funnel + dot OR funnel with line indicating "view"
- **Cliché**: just funnel (loses "saved view" semantic)
- **Reference**: Notion view bar; Airtable views

### Pin / Pinned page
- **Recommended forms**: pushpin (45° angle), OR thumbtack
- **Cliché**: bookmark (means saved); paperclip (means attached)
- **Reference**: Notion sidebar pinned pages; Apple Notes pinned

### Mention / @user
- **Recommended forms**: `@` symbol in rounded square OR person silhouette + `@`
- **Cliché**: just person icon (means profile)
- **Reference**: Notion mentions; Linear comments; Slack

### Comment / Inline comment
- **Recommended forms**: speech bubble + dot indicator for unread
- **Cliché**: same as universal Comment — but inline comment needs the ANCHORED indicator
- **Reference**: Google Docs comments; Notion comments; Figma

### Toggle list / Collapsible
- **Recommended forms**: chevron right (collapsed) / chevron down (expanded)
- **Cliché**: plus/minus (less universal than chevron)
- **Reference**: Notion toggle blocks; Apple Notes folders

### Status (Todo / In Progress / Done / Blocked)
- **Recommended forms**: empty circle (todo); half-fill (in progress); filled-check (done); X-shield (blocked)
- **Cliché**: text-only states; color-only encoding
- **Reference**: Linear status icons (canonical); Things 3

## Cliché map for productivity

| Cliché | Why it fails | Alternative |
|---|---|---|
| Folder tree for note hierarchy | Reads as desktop file system | Indented lines / outline shape |
| Chain for bidirectional links | Means generic hyperlink | Two opposing arrows or `[[]]` |
| 3-dot menu as block handle | Conflates with "more options" | 6-dot 2×3 grid |
| Tomato for focus session | Pomodoro brand-coupled | Clock face with active sector |
| Refresh for recurring event | Loses calendar | Calendar + circular arrow |
| Bookmark for "pinned" | Bookmark = saved (different) | Pushpin at 45° |
| Hamburger for kanban view | Loses kanban | 3 vertical columns |

## State-pair examples

1. **Status: Todo / In Progress / Done / Cancelled / Blocked** — Linear-style 5-state
2. **Toggle: Collapsed / Expanded** — chevron right / chevron down
3. **Comment: Unread / Read / Resolved** — bubble-dot / bubble-empty / bubble-check
4. **Sync: Synced / Syncing / Failed** — cloud-check / cloud-arrow-rotating / cloud-X
5. **Selection: Unselected / Selected / Indeterminate** — empty box / checked / dash-filled

## Industry-leading reference

Linear (status icon system, command palette). Notion (block handles, slash commands, database/collection icons). Things 3 (nested checklist + status). Obsidian (backlink and graph metaphors). Fantastical (calendar event language).
