# Education & Learning

## Industry overview

Education apps include K-12 (Khan Academy, Duolingo, Prodigy), higher ed (Coursera, edX, Canvas Student, Blackboard), language (Duolingo, Babbel, Memrise, Pimsleur), test prep (Magoosh, UWorld, Anki), code learning (Mimo, SoloLearn, Brilliant), and creative skills (MasterClass, Skillshare, Domestika). The domain has moderate distance from universal: most metaphors are extensions (lesson = list item; quiz = multiple choice list). The high-leverage additions are progress tracking (lesson progress bar, streak), certification (badge vs achievement vs certificate), structured content (quiz, flashcard, sandbox). Duolingo pioneered streak flame + gem currency + league vocabulary. Khan Academy established mastery point + level-up tree. Coursera/edX established lesson progress bar with section markers.

## Metaphor catalog

### Lesson / Module progress
- **Recommended forms**: horizontal bar with section markers; OR circles connected by line with fill state
- **Cliché**: generic progress bar (loses section context)
- **Reference**: Coursera lesson nav; Duolingo skill tree
- **Universal vocabulary cross-ref**: extends [Progress](../icon-vocabulary.md#progress)

### Quiz / Assessment
- **Recommended forms**: document + question mark, OR multiple-choice radio circles
- **Cliché**: just question mark (means help)
- **Reference**: Kahoot quiz; Duolingo lesson quiz
- **Universal vocabulary cross-ref**: composes [Document](../icon-vocabulary.md#document) + [Help / Info](../icon-vocabulary.md#help--info)

### Flashcard
- **Recommended forms**: rectangle with line in middle (front/back) OR two stacked rectangles
- **Cliché**: index card (over-detailed)
- **Reference**: Anki; Quizlet; Duolingo

### Certificate / Diploma
- **Recommended forms**: scroll + ribbon OR document + ribbon
- **Cliché**: just scroll (anachronistic)
- **Reference**: Coursera certificates; Credly badges
- **Universal vocabulary cross-ref**: extends [Document](../icon-vocabulary.md#document)

### Badge (skill badge)
- **Recommended forms**: shield with skill glyph OR hexagon with icon
- **Cliché**: trophy (different — achievement vs skill)
- **Reference**: Credly skill badges; Khan Academy badges
- **Universal vocabulary cross-ref**: extends [Shield / Protection](../icon-vocabulary.md#shield--protection)

### Achievement (vs Badge)
- **Recommended forms**: trophy OR star burst
- **Cliché**: medal (military feel); trophy (sports feel) — both OK in education context
- **Reference**: Duolingo achievements; Khan Academy

### Discussion forum / Q&A
- **Recommended forms**: speech bubbles overlapping (2 bubbles)
- **Cliché**: single bubble (means single comment)
- **Reference**: Coursera discussion; Slack channels (cross-domain); Reddit subreddit
- **Universal vocabulary cross-ref**: extends [Comment](../icon-vocabulary.md#comment)

### Instructor / Teacher
- **Recommended forms**: person silhouette + pointer/board, OR person + cap (graduation)
- **Cliché**: gendered figure
- **Reference**: MasterClass instructor profiles; Coursera
- **Universal vocabulary cross-ref**: extends [Profile / Account / Me](../icon-vocabulary.md#profile--account--me)

### Peer review
- **Recommended forms**: 2 person silhouettes + check OR document + 2 arrows
- **Cliché**: just review/comment (loses peer)
- **Reference**: Coursera peer review
- **Universal vocabulary cross-ref**: extends [Group / Community](../icon-vocabulary.md#group--community)

### Sandbox / Playground (code or interactive)
- **Recommended forms**: rectangle with `<>` brackets (code), OR rectangle with play triangle (interactive)
- **Cliché**: literal sandbox/playground icon
- **Reference**: Mimo playground; Brilliant interactive; Khan Academy code

### Streak (learning consistency)
- **Recommended forms**: flame + number badge
- **Cliché**: trophy (different)
- **Reference**: Duolingo streak; Memrise; Apple Streaks

### XP / Points
- **Recommended forms**: lightning + number OR star + number
- **Cliché**: dollar sign
- **Reference**: Duolingo XP; Khan Academy energy points
- **Universal vocabulary cross-ref**: extends Loyalty Points (e-commerce) — same shape, different domain

### League / Leaderboard
- **Recommended forms**: shield with rank (League); 1-2-3 podium (Leaderboard)
- **Cliché**: trophy alone (loses rank)
- **Reference**: Duolingo Diamond League; Khan Academy
- **Universal vocabulary cross-ref**: extends [Shield / Protection](../icon-vocabulary.md#shield--protection)

### Daily goal
- **Recommended forms**: ring with progress arc + center number (similar to activity ring)
- **Cliché**: generic checklist
- **Reference**: Duolingo daily goal; Khan Academy daily challenge
- **Universal vocabulary cross-ref**: extends Activity Ring (health) — cross-domain

### Hint / Skip
- **Recommended forms**: light bulb (hint) — but light-bulb is overloaded; OR question mark + arrow
- **Cliché**: light bulb means tip everywhere — fine here
- **Reference**: Duolingo hint; Quizlet

### Audio / Pronunciation
- **Recommended forms**: speaker + waves (small) OR microphone (for record-and-compare)
- **Cliché**: same as volume
- **Reference**: Duolingo pronunciation; Pimsleur audio
- **Universal vocabulary cross-ref**: extends [Volume](../icon-vocabulary.md#volume)

### Translate
- **Recommended forms**: "A→文" character pair OR globe + text
- **Cliché**: flag (politically loaded)
- **Reference**: Google Translate; Duolingo translate
- **Universal vocabulary cross-ref**: extends [Language](../icon-vocabulary.md#language)

### Subscription / Pro
- **Recommended forms**: crown OR diamond OR star + plus
- **Cliché**: dollar sign (means payment, not membership)
- **Reference**: Duolingo Super; Coursera Plus; MasterClass All Access

## Cliché map for education

| Cliché | Why it fails | Alternative |
|---|---|---|
| Trophy for both achievement and badge | Two concepts | Trophy = achievement; Shield/Hexagon = badge |
| Heart for "lives" in learning game | Conflates with like | Heart OK if scoped to game-context, with label |
| Generic progress bar for lessons | Loses section structure | Bar with section markers |
| Flag for "language" | Political | A→文 character pair |
| Light bulb everywhere | Means hint, info, tip | Light bulb = hint in education context |
| Apple icon for teacher | US-centric | Cap + person |
| Scroll for everything completion | Anachronistic | Document + ribbon |
| Generic person for instructor | Loses teacher | Person + cap or person + pointer |

## State-pair examples

1. **Lesson: Locked / Available / In progress / Completed / Mastered** — 5-state on skill-tree node
2. **Streak: 0 / 1-6 days / 7+ / 30+ / 100+** — flame size/intensity scaling
3. **Quiz answer: Unselected / Selected / Correct / Wrong** — radio button states
4. **Lives: 5 / 4 / 3 / 2 / 1 / 0 (regenerating)** — heart-row state
5. **League: Bronze / Silver / Gold / Diamond** — shield-rank progression

## Industry-leading reference

Duolingo (streak/league/XP gamification vocabulary). Khan Academy (skill-tree mastery). Coursera (certificate + section progress). MasterClass (instructor catalog). Anki (flashcard).
